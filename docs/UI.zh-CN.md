# UI

游戏界面由菜单页面、菜单对话框以及关卡自身的控件（"菜单"按钮、种子栏、工具和选卡界面）组成。界面使用原版的美术和位图字体绘制，响应鼠标、键盘和触屏操作。

## 操作

### 输入模式

游戏只从鼠标或触屏之一读取输入，二者不会同时生效：

- **桌面模式**读取鼠标事件。
- **移动模式**读取触屏事件。引擎判定为移动设备（`sys.isMobile`）时默认开启。`/mobile` 可在本次运行中切换，不会保存。

每个控件只监听当前模式的事件，因此即使浏览器把一次触摸同时报告为鼠标点击，按钮也只会触发一次。

### 鼠标

- **左键**：按下按钮、拿起种子包或铁铲、种植、收集阳光和金币、推进疯子戴夫的对话。
- **右键**：放下手中的种子包或工具。与原版一样，许多按钮也响应右键；关卡内的"菜单"按钮、"开始战斗！"等少数按钮只响应左键。
- **按住拖动**：按钮被按下后，指针移动时按下状态仍归该按钮。在按钮上松开则触发一次，在别处松开则取消；松开之前其他按钮不会高亮。
- **悬停**：显示提示框（种子包、铁铲、主菜单的奖杯、花园的"前往其他花园"按钮）；在商店中，疯子戴夫会介绍指针下的商品。
- **滚轮**：滚动成就页和较长的图鉴说明。选卡界面或植物图鉴有多页时（`/cheatseed`），在卡片上滚动滚轮可以翻页，每格一页；触控板的细小滚动会累积满一格后再翻页。
- **收集**：默认点击收集阳光和金币。`/collect move` 改为指针经过时收集，`/collect auto` 改为自动收集；两者都只处理普通掉落物。
- **对话框**可以拖动边框移动。

### 触屏

- **种植**：点击种子包将其选中，松手后仍保持选中。手指拖出种子包后会显示植物及行列辅助线，松手即种下。在无效位置松手，或回到原种子包上松手，都会取消。点击另一个已就绪的种子包则切换过去。
- **铁铲**：按住铁铲拿起，拖动瞄准，松手铲除；拖回铁铲按钮上则取消。
- **收集**：手指划过草坪时，会收集路径上的阳光和金币。
- **单指操作**：草坪从按下到松开只跟随一根手指。暂停会丢弃当前手势。
- **按钮**：从一个按钮滑到另一个按钮时，按下状态会转移到手指下的按钮，松手时触发该按钮。
- **列表**可以拖动滚动，松手后会继续滑动一小段。细滚动条可以拖动，点击滑槽则翻页。
- **滑块**：拖动滑钮，或点击滑槽使滑钮移到该处。
- **对话框**可以拖动边框移动。
- **商店**：手指松开时才开始购买，因此按住商品会先显示其介绍。使用鼠标时则在按下时开始购买。
- **文本框**会弹出屏幕键盘，文字由游戏自行绘制。在 iOS 上，文本框使用 ASCII 键盘并关闭自动更正。
- **调试控制台**：在 350 ms 内双击屏幕右下角（100 CSS 像素见方的区域）。移动模式下或任何移动设备上均可使用。

### 热键

热键默认关闭。`/hotkeys` 可开关热键，设置会在本机保存。开启后，前十个种子包会显示对应按键（1–9、0），铁铲槽显示 F。

| 按键 | 作用 |
| --- | --- |
| 1–9、0 | 拿起种子栏或传送带上对应位置的种子包。手中已有其他种子包时会直接换成该种子包；按下手中种子包的按键则将其放下。开场结束后才响应。 |
| F | 拿起或放回铁铲；手中有种子包时直接换成铁铲。 |
| D | 定格游戏（速度 0）；再按一次恢复之前的速度。 |
| R | 执行 `/repick`；重新选卡时相当于按下"开始战斗！"。 |
| S、C | 与输入 `/suncost`、`/cooldown` 一样切换阳光消耗和冷却：设置沿用到之后的关卡，并在屏幕上提示当前状态。 |

### 暂停、失焦与存档

- **"游戏暂停"**：按空格打开，其中有读报僵尸。它与游戏内选项是不同的对话框；游戏内选项由["菜单"按钮](#关卡界面)和 Esc 打开，同样会暂停关卡。点击"继续游戏"或按回车、空格、Esc 均回到原来的战场。
- **暂停期间**：打开"游戏暂停"时会保存关卡。两种对话框打开期间，服务端的游戏逻辑、场景中的 Reanim 动画、粒子、补间动画和音乐都会静止，但不改变全局时钟；恢复时只重新启用暂停前处于启用状态的动画组件。
- **失去焦点**（切换到其他窗口或标签页、最小化窗口、应用转入后台）时始终静音。开启自动暂停时（`/autopause`，默认开启，本机保存），若正处于关卡中且没有打开任何页面、对话框或调试控制台，还会打开"游戏暂停"，此时不播放暂停音效。
- **存档**：以下情况会保存正在进行的关卡：游戏被隐藏（标签页或应用转入后台）、窗口关闭（关闭按钮、Alt+F4 或 Cmd+Q）、打开"游戏暂停"、从关卡返回主菜单。进入有存档的关卡时会询问"继续游戏？"：选择"继续"、"重新开始本关卡"（需再次确认）或"取消"。

除选项之外的设备设置位于 `platform/debug/GameDebugSettings.ts`，存储键为 `pvz-remake:debug:settings`；只写入需要保留的设置，因此已废弃的设置会从旧数据中移除。

### 原版分辨率渲染

默认情况下，游戏按原版的方式绘制：每一帧先以 800×600 布局的每个单位对应一个像素合成（宽度随窗口而定，宽屏布局会更宽），再把这幅画面放大铺满窗口。因此旋转和缩放的部件与原版一样在同一像素网格上重采样，而不会比原版显示得更锐利。

- 画面在两个方向上都是偶数像素：取超出窗口的下一个偶数尺寸，以窗口的缩放比例从中心显示，窗口每侧裁掉不到一个单位。若尺寸为奇数，每个像素都会偏离布局网格半个单位，落在整数单位上的美术会糊到两个像素上。
- 场景摄像机绘制到这幅画面中，同时仍接收窗口的指针输入，因此点击位置与绘制位置一致。
- 拖动对话框时与原版一样按整数单位移动，框内文字不会因此抖动。

### 高分辨率

`/highresolution` 让游戏直接以窗口的实际像素绘制到窗口上。同样的美术会比原版显示得更清晰，拖动对话框时也可以自由移动。

### 锐度

`/sharpness {0-1}` 设置放大后像素边缘的锐利程度：两个像素之间的边缘在 `1 - sharpness` 个屏幕像素内过渡。`0` 在一整个屏幕像素内过渡（边缘最柔和）；`1` 接近最近邻缩放（边缘锐利，但在非整数缩放比例下，像素大小可能相差一个像素）。原版把放大交给显示设备完成，在多数显示设备上比普通线性过滤更锐利。

该设置作用于放大后的画面。开启 `/highresolution` 时没有这幅画面，此时改为作用于基础位图字体：字形按面积采样，缩小时笔画仍保持均匀；整数倍缩放不受影响。

### 种子包倾斜

`/tilted` 放大种子包中的图片（植物放大一半，僵尸放大到两倍），并顺时针旋转，使其探出种子包。图片只在内侧底边和背后一侧被裁切，上方和前方可以超出种子包。种子包背景、价格和点击区域保持原尺寸；切换开关时复用已加载的图片。手中的植物和草坪上的种植预览不会倾斜。

### 帧率

`/fps` 在原版 800×600 区域的左下角显示白色帧率计数，宽屏布局不会改变其位置。它按真实时间统计实际绘制的帧数，与暂停状态和游戏速度无关。

### 鼠标指针

开启原版鼠标指针（`/cursor`）时，游戏使用原版的鼠标指针：

| 指针 | 显示时机 |
| --- | --- |
| 大箭头 | 默认 |
| 手指 | 位于可点击对象上方时 |
| 拖动手形 | 拖动对话框时 |

文本框仍使用系统的 I 形光标。这些图片在导入资源时从原版可执行文件中提取，资源包可以替换。图片加载完成之前或加载失败时，继续使用系统指针。在打僵尸中，游戏会自行绘制木槌，指针下没有可点击对象时隐藏系统指针（仅桌面模式）。

### 触屏振动

`/haptics` 开关触屏振动，默认开启并在本机保存。Android 与 iOS 应用以及 Android 浏览器支持振动；iOS 浏览器没有振动接口，桌面设备没有振动马达。

以下情况会振动：

- 手指按到或滑到按钮上（种子包、工具、选卡卡片、图鉴卡片和主菜单的奖杯除外）；
- 滑钮每经过行程的二十分之一；
- 在图鉴中选中条目；
- 战场震动，例如爆炸；同一帧内以最强的一次震动决定振动强度。

爆炸的振动会延后 40 ms 游戏时间，并优先于较轻的振动；与上一次相隔不到 40 ms 的振动会合并。

## 选项

选项对话框（`dialogs/OptionsDialog.ts`）沿用原版布局：

- **"音量：音乐"**和**"音量：音效"**滑块立即改变音量。音效使用 0.65 的音量系数（`SFX_VOLUME_SCALE`）。
- **"3D加速"**始终开启，点击复选框会提示这是必需的。
- **"全屏幕显示"**在对话框关闭时生效；该设置在输入回调中提交，以保留浏览器的用户激活状态。在 Android 与 iOS 应用中始终开启，点击时会说明原因；浏览器不支持全屏时，勾选会给出提示。
- **关卡中**："查看图鉴"（图鉴解锁后，开场期间不显示）、"重新开始本关卡"（需确认；开场期间不显示）、"主菜单"（需确认，并保存关卡；开场期间直接离开）和"返回游戏"。
- **主菜单中**："模组"在选项之上打开模组管理器（见[模组](MODS.zh-CN.md)），"确定"关闭选项。
- 回车和 Esc 与"返回游戏"或"确定"一样关闭对话框。

设置仍使用 `pvz-remake:settings:options` 存储键。

## 界面

### 启动（`StartupScreen`）

- PopCap 标志在 200 个逻辑步内淡入、停留、淡出（淡入淡出各 50 步）。游戏启动时显示，应用待处理的模组变更时也会显示，变更就在显示期间完成；返回标题画面时跳过。
- 随后标题画面按 `TitleScreen` 的方式播放。标题落下，加载条（314 px）从下方升起：一条泥土随加载进度被草皮覆盖，前端是滚动的草皮卷，沿途在原版的五个阈值处冒出嫩芽和僵尸头（加载条的 0.11、0.32、0.54、0.72 和 0.906；1.0.0.1051、1.2.0.1073 和 1.2.0.1096 中均为 0.906）。计时使用全局时钟的 100 Hz 逻辑步；效果（`pvz:loadbar_sprout` 和 `pvz:loadbar_zombiehead`，每秒 18 帧）由当前的 `ReanimPlayer` 播放。它们与其他资源一起由 `npm run build:content` 从 `main.pak` 转换而来，该命令同时重新打包内置 ZIP（见[开发](DEVELOPMENT.zh-CN.md)）。
- 进度反映实际的工作量。Release 版本先预加载全部资源（Debug 版本和 iOS 浏览器在用到时才加载图片：HD 资源包解码后会超出那里的页面内存上限），再准备主菜单的图片和动画，最后构建成就页并在加载画面后面绘制一次。
- 加载完成且加载条显示"点击开始！"后，点击它、点击或触摸画面任意位置，或按任意键即可开始；加载条遵循按钮的鼠标规则。准备好的主菜单保持隐藏，由这次输入触发入场时直接复用。

### 主菜单（`MainMenuScreen`）

- 表现定义 `mainMenu`（`main-menu.json`）包含原版的按钮图片、轨道偏移、多边形点击区域以及各动画的速率（`fps`，每秒帧数）。界面用当前的 `ReanimPlayer` 按原版的绘制顺序组合这些内容。
- 入场依次播放 `open` 和 `sign`，并停在最后一帧。云、草和右侧的三朵花各自独立播放动画；每朵花被点击时播放一次动画。没有玩家时不绘制草，入场结束后打开创建玩家对话框；有了玩家之后木牌才会落下。
- 墓碑按钮分别进入冒险模式、迷你游戏、益智模式和生存模式，使用多边形点击区域和墓碑按钮音效。其他按钮包括玩家木牌和僵尸大头贴木牌，以及花园、商店、图鉴、成就、选项、帮助和退出按钮，使用点击声。悬停时播放原版的提示音。退出前会先询问。
- 锁定规则遵循 `GameSelector::SyncButtons`：模式解锁前，按钮显示为灰色，指针经过时保持普通图片、不发出声音，点击时显示其锁定说明，告知解锁条件。图鉴、商店和休闲花园在解锁前隐藏。没有玩家时所有模式都处于锁定状态。
- 冒险按钮根据档案显示：新玩家显示"开始冒险"，否则显示"冒险模式"图片及当前关卡数字（如 2-5）。点击后播放 4.5 秒的闪烁（按钮每 0.1 秒明暗交替）、僵尸手、失败音乐、泥土音效，并在 1.25 秒时播放邪恶笑声，然后进入档案中当前的冒险关卡（`play`；若有关卡存档，会询问是否继续）。
- 完成冒险模式后，左侧出现向日葵奖杯，赢得全部 48 个挑战奖杯（迷你游戏、益智模式和生存模式的全部奖杯）后变为黄金向日葵奖杯，带有原版的闪光粒子；指针位于 (50, 250)–(135, 475) 时，在固定位置显示提示框。
- 木牌用于切换玩家（见[菜单对话框](#菜单对话框)）和打开僵尸大头贴；后者尚未开放，会显示尚未开放的提示。

### 挑战页面（`ChallengeScreen`）

`ChallengeScreen` 根据表现定义中的 `challenges` 布局，绘制原版的迷你游戏、益智模式和生存模式缩略图按钮（20、20 和 11 个），并根据档案中的奖杯数显示已获得的奖杯（已完成数 / 可获得奖杯的项目数；无限模式没有奖杯）。按钮沿用 `UI.button` 的捕获和外观状态，悬停时文字变红。目前选择任何挑战都会显示"即将推出"对话框（"此模式尚未开放。"）。"返回菜单"按钮与 UI 区域左边缘保持固定距离。

### 图鉴（`AlmanacScreen`）

- `AlmanacScreen` 提供植物种子包、静止的僵尸缩略图、选中状态、详情卡片、花费、恢复时间标签以及彩色位图说明文字。索引页显示向日葵和普通僵尸，并通向"查看植物"（`seed` 按钮）和"查看僵尸"。
- 植物列表显示玩家已拥有的种子包；选中的植物会在其地面上播放动画，并显示名称、说明、"花费"和"恢复时间"。僵尸列表显示冒险模式已推进到的僵尸，其余显示为空白窗口；在当前关卡首次登场的僵尸，说明处显示"？？？"，到之后的关卡才显示说明。
- `AlmanacEntityView` 显示详情中的植物或僵尸，但不创建战斗实体。在战场之外，实体相当于原版中不在场的 `Plant`（`IsInPlay()` 为 false）或 `Zombie`（`ZOMBIE_WAVE_UI`）：其动画遵循关卡的规则，植物按 `shared/content/plantAnimation`（服务端在关卡中也用它推进植物），僵尸的站立动作按 `shared/content/zombieAnimation`（`Zombie::LoadReanim`），并由 `client/view/offBoard.ts` 绘制（见[场地外视图与加载](ARCHITECTURE.zh-CN.md#场地外视图与加载)）。
- 在详情中，植物或僵尸会按其表现定义中的 `almanacOffset` 偏离通常位置，使用原版 y 轴向下的像素（`AlmanacDialog::DrawPlants` 与 `DrawZombies`）：咬咬碑下移 55，橄榄球僵尸左移 10。僵尸缩略图（`AlmanacZombiePortrait`）使用表现定义中的 `portrait`，以该位置和比例静止显示僵尸，对应原版缓存的半尺寸帧。位置、缩放和影子通过视图的 `draw` 参数传入。
- 恢复时间标签：没有冷却为"无"，750 逻辑步为"短"，3000 为"长"，其余为"非常长"。
- 较长的说明可以滚动。`AlmanacText` 保留原版的标记（`{KEYWORD}`、`{STAT}`、`{FLAVOR}`、`{NOCTURNAL}`、`{AQUATIC}`、`{METAL}`、`{KEYMETAL}`、`{NORMAL}`、`{SHORTLINE}`、`{EXTRASHORTLINE}`），并在 `UI.scroll` 中排版。滚动遵循 Steam 1096 的 `AlmanacDialog`：每页为框高的 85%（因此末尾通常留出 15% 空白），每格滚轮滚动文本高度的 5%，滚动条使用当前页面的配色。文字绘制时比测量宽度窄 7 px，滚动范围会相应延长，以显示因此多出的一行。
- 共用的 `UIScroll` 和 `ScrollGesture` 负责滚轮、滑块拖动和移动端触摸滚动，惯性由全局时钟驱动。
- 开启 `/cheatseed` 时，植物列表有更多页（模组种子，然后是隐藏卡片），可用"上一页"和"下一页"（后者图片镜像）或在卡片上滚动滚轮翻页，见[调试指令](DEBUG_CLI.zh-CN.md)。
- 底部有"图鉴索引"和"关闭"按钮。它们使用专用的 `almanacIndex` 和 `almanacClose` 样式，位于原版位置，并与 UI 区域边缘保持固定距离。

### 商店（`StoreScreen`）

- `StoreScreen` 提供疯子戴夫的车、招牌入场、四页商品、悬停介绍、金币计数，以及 0.5 秒的后备箱翻页（翻页开始的 0.15 秒内车辆抖动），全部运行在全局时钟上。各页随冒险进度逐步开放，用车尾灯翻页。商品分两排、每排四件，带价签，可能标为"即将推出"或"已售出"。
- 疯子戴夫（`CrazyDaveView`）在原版 `StoreScreen` 绘制他的位置入场，并在对话气泡中说话：介绍指针或手指下的商品，并不时按 `storeDialogue` 表现定义中的权重随机闲聊；不会重复上一句，`completed` 台词只在完成冒险模式后出现。原版把翻页箭头（车尾灯）画在他上面，导致他入场时手臂从尾灯后面穿过；本项目把箭头放在他下方。
- `server/menu/storeCatalog` 从当前档案读取进度和购买次数（档案的 `purchases`，按商店物品 ID 记录），用于判断可购买状态、价格、库存上限以及确认购买。金币使用原版单位（存储的每枚金币为 $10）。API 在扣款前重新读取档案，并在后端保存；`/money` 的修改会立即反映到已打开的商店中。
- 购买前需要确认，金币不足时会提示；购买卡片槽后会提示新的卡片槽数量，购买智慧树后会询问是否前往。购买的物品在游戏中的效果由相应的系统负责。
- 从花园或选卡界面打开时，返回按钮显示"返回"并回到原处；否则为主菜单按钮。

### 成就（`AchievementScreen`）

- 主菜单向上滑出，成就页从下方升起（见[过渡与淡入](#过渡与淡入)）。页面通过 `getAchievements()` 读取成就定义（玩法定义 `achievements` 表：基础游戏的 21 个成就，按原版顺序，模组可以扩展）和当前玩家已获得的成就 ID；构建时读取一次，之后每次显示时重新读取，并滚回顶部。触发条件、授予方式和奖励页的列表见[成就](ACHIEVEMENTS.zh-CN.md)。
- 布局遵循 `AchievementsWidget`：两列间隔 290 px，各行从 y 178 开始、间隔 57 px，70 px 的图集格以 0.8 倍（56 px）绘制，绿色标题，自动换行的白色位图说明文字。已获得的成就图标明亮（不透明度 255），其余暗淡（不透明度 32）。模组可以替换整个背景层（顶部、平铺的地洞和底部的中国）而不影响装饰和控件。
- 列表可以用滚轮、上下方向键、拖动（移动模式下）以及右下角的"更多"石头滚动。共用的 `UIScroll` 每格滚轮滚动 80 px，没有缓动。"更多"石头在 0.25 秒内向下滚动 230 px，显示列表的其余部分；再次点击时，其"顶部"状态会滚回去。只有向下滚动时播放石头音效。触摸拖动带惯性；所有运动都遵循全局时钟。
- 方向键遵循年度版的 `AchievementsWidget::KeyDown`：每次按下把速度设为 30，此后每 10 ms 减 1，并滚动等于当前速度的像素（每按一次约 435 px）；按键自动重复只会重置速度，不会叠加。
- 左上角的按钮返回主菜单。平铺的地下背景和这个返回控件随内容一起滚动。滚动不会请求数据，也不会授予成就。

### 花园、帮助与奖励页

- 四个休闲花园页面只显示背景和按钮（主菜单、前往其他花园、商店），花园本身尚未实现。`MenuPageControls` 提供这些按钮以及成就页的返回按钮。切换花园使用 `clickOnPress`，其提示框通过 `offset` 保持原先的中心 x=599、顶端 y=52。
- 帮助页显示帮助便条，并在原版位置提供 `seed` 样式的"主菜单"按钮，用于返回主菜单。其淡入见[过渡与淡入](#过渡与淡入)。
- 奖励页（`AwardScreen`）显示新植物、物品或便条：以两倍大小绘制新的种子包，或绘制物品图片、便条图片，并显示名称和说明，以及用于继续的 `seed` 样式"下一关！"按钮（或该奖励先要打开的页面的按钮）。部分奖励页右上角还有一个小的"主菜单"按钮。奖励页使用原版按钮图片，并保留早先的冒险 1-1 重玩路径：在奖励页按 R 会导航到 `restart`。
- 已获得但尚未显示过（在关卡中或此前的列表中）的成就会先逐条列出（`AwardAchievements`，对应 `AwardScreen::DrawAchievements`）：每行在 100 逻辑步内从 y 750 滑入，从第 150 步起每 100 步一行，行距 76 px；最后一行到位后出现"继续"按钮。在此期间页面按键（见[键盘](#键盘)）照常有效。

**"你是谁？"**（`dialogs/UserDialog.ts`）是玩家列表。它通过 `MenuApi` 选择、创建、重命名和删除玩家；由后端校验并保存这些操作。

- 最多显示八名玩家，当前玩家排在最前。单击名字选中，双击或点击"确定"切换，"取消"保留当前玩家。"重命名"和"删除"作用于选中的玩家；最后一行用于创建新玩家。
- 名字遵循原版的限制：最多 12 个 ASCII 字母、数字和空格；连续空格合并为一个，名字不能为空，也不能与其他玩家重名（不区分大小写）。

- 游戏始终需要一名玩家：首次启动以及删除最后一名玩家后，都会要求创建新玩家。保留的主菜单会刷新玩家名字和冒险进度。

### 关卡界面

- **"菜单"按钮**：原版的 117×46 石质按钮，位于右上角 (681, -10)，由 `LevelHudPresenter` 创建，在关卡开场结束后显示（失败后不显示）。它不响应右键。手中拿着种子包或工具时，点击它只会放下手中之物；否则打开游戏内[选项](#选项)对话框。暂停见[暂停、失焦与存档](#暂停失焦与存档)。

- **选卡界面**（`LevelSeedChooser`，对应原版 `SeedChooserScreen`）：提供哪些种子、选中了哪些由服务端决定；客户端负责移动面板和卡片。

  - 网格共 8 列，列距 53 px；五行时行距 73 px，有卡片位于第 40–47 格时改为六行、行距 70 px；尚未解锁的种子在其位置留下剪影。
  - 点击或触摸卡片将其放入种子栏，点击已选的卡片则将其放回。卡片在网格与种子栏之间飞行 25 逻辑步（在卡片槽之间移动时为 15 步），新的点击会先让所有飞行中的卡片落位。
  - 提示框介绍每张卡片。关卡不推荐的卡片显示为灰色（在网格中等待时变暗为 115），提示框中附有红色警告。
  - "开始战斗！"（`seed` 样式，黄色字体）只在种子栏填满时显示为可用；开启 `/cheatseed` 时，选中任意一张即可。若关卡有警告，之后会依次询问，选择"重选"则回到选卡。
  - "图鉴"和"商店"按钮（`seedSmall`）在图鉴和商店解锁后、`LawnApp::CanShowAlmanac` 和 `CanShowStore` 允许时出现，在暂停的关卡之上打开对应页面，关卡音乐继续播放；重新选卡时不显示这两个按钮。点击街道上的僵尸则打开它的图鉴条目。
  - 开启 `/cheatseed` 时，"(上一页)"和"(下一页)"使用 `text` 样式。
- **触屏种植**的手势见[触屏](#触屏)，由 `LevelInputPresenter` 处理。划动收集每 24 px 采样一次，选中高亮复用 `SeedPacketView` 的移动模式，种植使用现有的后端命令。

## 窗口位置（Windows 与 macOS）

原生 Windows 与 macOS 版本会像原版的 `PreferredX`/`PreferredY` 注册表值一样记住窗口位置。`native/engine/common/Classes/Game.cpp` 跟踪普通窗口（非全屏、非最大化、非最小化）的位置和尺寸，在窗口关闭时写入可写目录下的 `window.txt`，并在创建下一个窗口之前读取。若保存的窗口顶边中点已不在任何显示器的可用区域内，引擎改为居中显示 800×600 的窗口。

### 约定

- **坐标**：所有工厂选项、多边形和偏移都使用父节点内的局部像素坐标，x 向右、y 向下，与原版一致。多数界面以 800×600 布局的左上角为原点排布。
- **值**：在代码中设置控件的 `value` 不会触发回调；只有用户输入才会调用 `onChange`。
- **文本**：`ui.text(key)` 读取一张合并后的文本表：先是基础游戏的文本，再依次叠加每个运行中模组自己的条目和翻译。模组只能在自己的命名空间中新增条目，其他新增会被拒绝并记录日志。缺失的键会直接显示键名并记录错误。`ui.format(key, args)` 按顺序填入 `%s`/`%d`，与原版的 `StrFormat` 相同；`ui.hasText(key)` 判断某个键是否存在（用于只在有文本时才显示的内容，如模组植物的说明）；`ui.locale` 是已安装文本的语言（BCP 47，由文本包的 manifest 声明）。
- **时间**：界面的计时和动画运行在全局时钟（`core/GameClock`）上，多数以原版的 10 ms 逻辑步计。
- **数据**：界面只通过 `MenuApi` 读取和修改档案数据，见[菜单后端](ARCHITECTURE.zh-CN.md#菜单后端)。

### UI 工厂

`client/ui/UI.ts` 负责创建文本标签、图片、按钮、文本输入框、复选框、下拉选择、滑块、滚动区域、提示框和对话框。文字由现有的 `FontRenderer` 使用原版位图字体绘制，控件沿用原版的纹理与交互。`UI.load()` 加载运行中的 UI 资源（包含所有模组）；`UI.recovery()` 只加载基础游戏的资源（保留已加载的语言包），供模组出错后的恢复对话框使用。

```ts
const ui = await UI.load()
const label = ui.label(parent, { text: 'Music', x: 20, y: 30 })
const button = ui.button(parent, { text: 'OK', x: 20, y: 80, onClick: close })
const slider = ui.slider(parent, { x: 220, y: 30, value: 0.85, onChange: setVolume })
const checkbox = ui.checkbox(parent, { x: 220, y: 80, value: true, onChange: setChecked })
const select = ui.select(parent, { x: 20, y: 140, items: ['A', 'B'], value: 0, onChange: selectItem })
const input = ui.input(parent, { x: 20, y: 190, width: 300, maxLength: 12, onSubmit: saveName })
const confirmed = await ui.dialog(parent, { title: 'Continue?', cancelText: 'CANCEL' }).result
```

文本标签提供 `text`、`color` 和 `setPosition(x, y)`；按钮提供 `setText()` 和 `interactable`；输入框、复选框、下拉选择和滑块提供 `value`。对话框会阻挡其下方的输入，可以拖动，位于最上层时响应回车、空格和 Esc，并通过 `close()` 关闭。

#### 文本标签

`ui.label(parent, options)` 接受字体预设或已加载的 `BitmapFontAssets`，以及 `x`、`y`、`width`（自动换行）、`fontSize`、`lineSpacing`、`color`、`align` 和 `baseline`（把 `y` 放在基线上）。`node` 绑定已有的预制体文本节点，而不是再添加一个渲染器。`pixelAlign` 对最终位置取整，用于原版的 HUD 文字。

所有关卡共用的关卡 HUD 用这些标签显示阳光数、关卡名、玩家房子的名称和提示；其字体来自内容注册表，因此模组覆盖同样生效。种子包使用 `UIButton` 处理按下、捕获和模态，暂停关卡输入时会禁用这些组件。冷却、选中、闪光、提示动画和进度条仍使用各自的专门渲染。

#### 按钮

`ui.button(parent, options)` 通过 `skin` 选择原版的按钮样式。尺寸默认取源图片的尺寸，石质按钮（以及 `text` 样式）默认 180×46。

| `skin` | 外观 |
| --- | --- |
| `stone` | 默认的平铺石质按钮，悬停时文字高亮 |
| `back` | 选项中的大号返回按钮，360×100 |
| `seed` | 选卡界面的大按钮，156×42，带叠加发光和禁用图片 |
| `seedSmall` | 选卡界面的小按钮，111×26，悬停时换成高亮图片 |
| `almanacIndex` | 图鉴底部的索引按钮，164×26，文字向右偏移 |
| `almanacClose` | 图鉴底部的关闭按钮，89×26，文字向左偏移 |
| `image` | 自定义图片按钮，可选带 `text`；提供 `images` 时自动采用 |
| `text` | 只有文字、没有图片的按钮，悬停时变为 `hoverColor`，与选卡界面的 `(Debug Play)` 按钮相同 |

```ts
ui.button(parent, { skin: 'seed', text: 'Continue', x: 20, y: 80, onClick: next })
ui.button(parent, {
    x: 400, y: 100,
    images: { normal, hover, pressed, disabled }, // SpriteFrames; only normal is required
    polygon: [[7, 1], [328, 30], [314, 125], [1, 78]],
    onClick: startAdventure,
})
```

图片用 `modResources.sprite(id)` 加载，它返回拥有该图片、优先级最高的运行中资源包的 `SpriteFrame`。

| 选项 | 默认值 | 作用 |
| --- | --- | --- |
| `images` | 样式自带 | 必须提供 `normal`。缺少的状态回退到普通图片；`pressed` 先回退到 `hover`。没有禁用图片时，禁用的按钮以半透明绘制。 |
| `imageBox` | 整个按钮 | 让图片范围与点击区域分开。主菜单底部的按钮借此保留原版较大的点击区域，同时图片保持原始尺寸。 |
| `mirrored` | `false` | 水平镜像绘制图片，文字向相反方向偏移（图鉴的"下一页"）。 |
| `font`、`hoverFont`、`color`、`hoverColor`、`disabledColor` | 样式自带 | 文字的字体和颜色；`hoverColor` 即原版的 `GameButton::SetLabelHiliteColor`。 |
| `pressOffset` | `seed` 和图鉴底部样式为 `[1, 1]`，其余为 `[0, 0]` | 按下时移动外观，点击区域不变。 |
| `pressSound` | `seed`、`seedSmall` 和图鉴底部样式为点击声（Tap），`stone` 和 `back` 为墓碑按钮音效，其余为按钮点击声 | 按下时播放；设为 `null` 则静音。 |
| `clickSound` | 无 | 与动作一同播放；设为 `null` 则静音。 |
| `hoverSound` | 无 | 指针真正进入按钮时播放。 |
| `clickOnPress` | `false` | 鼠标或触摸按下时立即执行动作，不捕获指针。切换花园使用此方式。 |
| `rightClickTriggers` | `true` | 设为 `false` 时按钮忽略右键。 |
| `rightClickPressesVisual` | `true`，图鉴底部样式为 `false` | 设为 `false` 时保留右键触发，但不显示按下外观，图鉴底部按钮即如此。 |
| `releaseToNormalOnPressOut` | `true`，`image` 为 `false` | 按住拖出按钮时按钮恢复普通外观；`image` 按钮保留高亮，但取消按下偏移。两种情况下，指针移出后都恢复默认指针。 |
| `refreshHoverOnEnable` | `true` | 启用按钮时重新检查悬停。主菜单的按钮与原版一样关闭此项。 |
| `enabled` | `true` | `interactable` 的初始值。 |
| `tooltip` | 无 | 悬停时显示的提示框（见[提示框](#提示框)）。 |
| `onClick` | 无 | 按钮的动作，在按钮内松开时执行（使用 `clickOnPress` 时在按下时执行）。 |

`UIButton` 组件还提供：`touchSlide`（跟随手指并在松开时触发；自带拖动手势的控件会关闭）、`changeCursor`（显示手指指针）、`hapticsEnabled`、`canInteract`（临时的输入开关，关闭时保持普通外观）、`onHoverEnter`、`onHoverChange`、`onStateChange`，以及 `trigger()`：在按钮当前可以按下时，用键盘模拟按下（播放音效并执行动作）。工厂方法会在激活节点之前设置好图片、回调和多边形，避免构建过程中提前触发悬停。

**捕获。** `UIButton` 沿用原版的共享捕获机制。左键或右键按下后，拖动指针时按下状态仍归该按钮，松开之前其他按钮都不会悬停。在按钮内松开触发一次，在按钮外松开则取消。桌面模式监听鼠标事件，移动模式监听触屏事件，因此模拟出的触摸不会让按钮触发两次。`onHoverEnter` 跟踪指针真正进入按钮的时刻，与外观状态无关，并负责播放 `hoverSound`。禁用或销毁按钮、切换页面都会取消捕获。

**多边形点击区域。** `polygon` 列出从按钮左上角起算的局部像素坐标，x 向右、y 向下，位于按钮的 `width` 和 `height` 之内。顶点数不少于三个时使用多边形判定，否则使用矩形。边上的点算作内部，支持凹多边形，并考虑节点的缩放和旋转。悬停、鼠标左右键、触摸以及在外部松开都使用同一区域；区域之外的点会穿透到下方的控件。按下偏移只移动外观。

#### 提示框

按钮的 `tooltip` 可以是字符串，也可以是 `{ text, title?, warning?, font?, maxWidth?, gap?, offset?, surface?, fixed? }`。弹出框沿用原版配色：淡黄色底和黑色边框，正文使用 Pico129（`packetCost`），可选的标题使用 Pix118Bold，可选的警告行为红色。

- 跟随实际的悬停状态，显示在锚点下方（`gap`，默认 4 px），下方空间不足时翻到上方，并保持在所在的视口、遮罩或 Canvas 之内，距边缘 2 px。
- 长文本按原版规则换行，在达到目标宽度后的第一个断点处断行；中日韩文字可在字符之间断行，但不会断在闭合标点之前或开启标点之后。
- `offset: [x, y]` 在边缘限位之前向右、向下调整位置。花园的提示框使用此方式（见[花园、帮助与奖励页](#花园帮助与奖励页)）。
- `fixed` 让弹出框左上角对齐锚点左上角（相当于固定位置的 `ToolTipWidget`，主菜单的奖杯使用此方式）；控件位于裁剪区域内时，可用 `surface` 把弹出框画到另一个节点上。
- `ui.tooltip(anchor, options)` 创建一个手动控制的提示框，提供 `show()`、`hide()`，以及可修改的 `text`、`title` 和 `warning`。禁用锚点会隐藏弹出框，销毁锚点会将其移除。

#### 文本输入

`ui.input(parent, options)` 在原版输入框美术上创建 `UIInput`。它提供 `value`、`interactable`、`focus()`、`blur()`、`selectAll()`、`hasFocus`、`hasSelection` 和 `color`，并调用 `onChange`、`onSubmit` 和 `onCancel`。

- `filter` 清理输入，`maxLength` 限制长度。无论 `filter` 是否允许，位图字体无法绘制的字符都会被丢弃，并且只保留第一行。
- 键盘、输入法和剪贴板由 Cocos 的 `EditBox` 处理；原版位图文字、输入框美术、选区和光标由游戏绘制。对浏览器选区的访问封装在组件内部。
- 指针可以放置或拖动光标，双击（500 ms、6 px 以内）全选。悬停时显示 I 形光标。
- 在获得焦点的文本框中输入空格不会确认对话框。除非 `onKey` 接管，Tab 会在文本框之间切换；`completion` 在光标后绘制淡色的补全后缀，`onCompletionTap` 允许点击接受该后缀（调试控制台使用）。
- 上层打开模态对话框时文本框会失去焦点；玩家对话框会在校验提示关闭后恢复焦点。
- `keyboardType`（默认 ASCII）和 `autocorrect`（默认关闭）设置 iOS 键盘。在 iOS 浏览器中，隐藏的 DOM 输入框固定在左上角，因此键盘弹出时页面不会平移；键盘收起时，点击文本框会作为普通点击交给 WebKit，使文本框能够重新获得键盘焦点。在 Android 上，原生编辑器隐藏在游戏画面之内，正在组字的文本会随输入实时显示。
- 移动模式下，对话框中的输入框会把对话框面板上移。

#### 滚动区域

`ui.scroll(parent, { x, y, width, height, contentHeight, wheelStep?, pageHeight?, scrollbar?, colors?, wheelDuration? })` 创建垂直滚动的 `UIScroll`，滚动条为年度版的 `ScrollbarWidget`：宽 8 px，左边缘位于区域右边缘以内 6 px，没有箭头按钮。把文本标签、图片或其他节点加到 `scroll.content` 中，并以 `scroll.contentWidth` 排版（显示滚动条时窄 7 px）。

- `scroll.offset` 立即滚动到指定像素偏移；`scroll.scrollTo(offset, seconds)` 以双 S 曲线动画滚动过去。
- 内容变化后调用 `scroll.setContentHeight(height, drawnHeight?)`。`drawnHeight` 让滚动范围覆盖比测量高度更高的绘制内容，而不改变滑块。
- 组件负责裁剪、滚动条的自动显隐、原版滑块的绘制与拖动、滑槽翻页（按住滑槽时，经过 25 次 10 ms 的更新后再次翻页，此后每 5 次翻一页）、触摸惯性以及监听器清理，运行在全局时钟上。
- `wheelStep` 是每格滚轮滚动的像素数（默认 12）。一格对应滚轮增量 120；触控板较小的增量按比例滚动更少，每个事件最多一格。
- `pageHeight`（默认等于高度）是点击滑槽时翻页的距离，滚动到底时仍保留这么多内容可见。`colors` 是滚动条的六种 `ScrollbarWidget` 颜色（滑槽、翻页中的滑槽、滑块、边缘、阴影、高光）；默认使用僵尸图鉴的配色。
- `scrollbar: false` 隐藏滚动条并保留完整的内容宽度。`wheelDuration` 为滚轮滚动启用之前的双 S 缓动。

#### 滑块、复选框与下拉选择

- `ui.slider` 绘制原版的滑槽和滑钮，默认宽 135 px。按住滑钮可以拖动；按在滑槽上则把滑钮移到按下处。松开时播放点击声。
- `ui.checkbox` 尺寸为 46×45，按下时切换。提供 `locked` 时，按下改为调用 `locked()` 而不切换；选项对话框将其用于 3D 加速，以及被强制开启的全屏。
- `ui.select` 是显示当前项的石质按钮，点击后打开一个对话框，每个选项对应一个按钮。

#### 对话框框体

`ui.dialog(parent, options)` 构建原版的对话框框体，或使用单张 `background` 图片（选项对话框），并像 `LawnApp::CenterDialog` 一样按整数单位居中。

| 选项 | 作用 |
| --- | --- |
| `title`、`message` | 标题（`title` 字体）和自动换行的正文（`body` 字体），使用原版的文字颜色 |
| `width`、`height`、`extraWidth`、`extraHeight` | 尺寸；默认像 `LawnDialog::CalcSize` 一样根据标题和正文扩展 |
| `tall` | 使用加高的底部框体 |
| `centerMessage` | 设为 `false` 时正文靠上排列，而不是在区域内居中 |
| `contentInsetTopExtra`、`spaceAfterHeader` | 标题上方的额外间距，以及标题下方的间距（默认 3，即 `LawnDialog` 的值；`Dialog` 为 10） |
| `footer`、`confirmText`、`cancelText`、`buttons` | 底部按钮："确定"、"确定"和"取消"，或最多两个自定义按钮外加一个可选的通栏第三按钮 |
| `clickSound` | 底部按钮松开以及键盘确认或取消时的音效 |
| `onClose` | 关闭时调用，参数表示是否已确认 |

`UIDialog` 维护一个对话框栈。最上层的对话框在已获得焦点的 `UIInput` 和自身的 `onKeyDown` 之后处理回车、空格（确认）和 Esc（取消）。`result` 在关闭时给出是否已确认；`onConfirm` 和 `onCancel` 可以替换。对话框是模态的（阻挡下方输入，并为悬停开启模态范围），除非 `draggable` 为 false，否则可以拖动面板背景移动（显示拖动手形指针），并始终保持在视口之内，视口尺寸变化时重新调整位置。未开启 `/highresolution` 时，拖动的对话框按整数单位移动。

### 输入、悬停与鼠标指针

- **`UIHoverManager`** 挂在应用的根节点上。它记录最近一次的指针位置，并在最上层的模态根节点（打开的对话框和当前页面）范围内询问各个客户端（按钮、输入框、对话框拖动、关卡 HUD）哪个处于悬停状态。过渡动画期间完全阻挡输入（`beginInputBlock`）。关闭对话框后，会根据记录的鼠标位置恢复悬停。它也负责设置鼠标指针：请求指针的客户端上方显示手指，文本框上方显示 I 形光标，拖动对话框时显示拖动手形；没有悬停对象时显示默认箭头或不显示（`setIdleCursor`，用于打僵尸的木槌，对应 `Board::UpdateCursor`）。
- **`CursorManager`** 把 `default`、`pointer` 和 `grabbing` 映射到 `pvz:cursor_pointer`、`pvz:cursor_hand` 和 `pvz:cursor_dragging`，热点为原版的 (0, 0)、(11, 4) 和 (15, 10)，替换为更高密度的图片时按比例缩放。网页版使用 CSS 指针；原生 Windows 与 macOS 通过引擎的 `jsb.setCursorImage` 使用 SDL 彩色指针。其他样式，以及关闭 `/cursor` 后的所有样式，均使用系统指针。部分装饰性控件保持箭头（`changeCursor = false`）：成就页的返回按钮和"更多"石头、主菜单的花和奖杯。
- **`ScrollGesture`** 把滚轮增量换算为格数（120 为一格，每个事件最多一格），并实现带惯性的触摸拖动：若手指在松开前 100 ms 内移动过，松开时的速度会延续下去，逐渐衰减到每秒 8 px 以下为止。
- **`WheelPageTurner`** 让滚轮像翻页按钮一样翻页：每格一页，向下为下一页，并播放点击声。触控板的细小滚动累积满一格才翻页，改变方向时重新累积。

### 菜单外壳

#### 页面与对话框

`client/screens/MenuPages.ts` 声明了以下页面：`splash`、`title`、`main`、`minigames`、`puzzle`、`survival`、`almanac`、`plants`、`zombies`、`store`、`garden`、`mushroom`、`aquarium`、`tree`、`achievements`、`help` 和 `award`。`MENU_PAGES` 的每一项给出该页面的音乐、`heading`、背景、各按钮的目标、`back` 目标，以及是否保留上一页（`retainPrevious`）。

选项（主菜单中为 `options`，关卡中为 `gameOptions`）、玩家列表、退出确认、暂停对话框和游戏结束不是页面，而是菜单对话框（`client/dialogs/MenuDialog.ts`），与原版的 Dialog 相同。`GameApp.openDialog` 一次只打开一个，覆盖在当前页面或暂停的关卡之上；下方的页面或关卡保持挂载，在对话框关闭前不接收输入。主菜单按钮用同一个 `target` 字段指向页面或对话框。

- `MenuPages.heading` 声明原版的标题字体、基线和颜色，文字取自 `pvz:strings`；没有临时的标题栏。商店改为绘制原版的招牌，奖励页则绘制自己的标题。
- 商店、图鉴各页和成就页保留调用它的页面（`retainPrevious`），因此关闭后不会重播主菜单的入场动画；花园也以同样方式保留在商店之下。帮助、挑战页面、花园、标题画面和游戏本身会替换并销毁主菜单；返回时创建新的主菜单并重新播放入场动画。
- 成就页只在加载画面后面构建一次，之后不会销毁；每次进入时刷新。
- 导航历史：图鉴索引及其两个列表算作同一个页面，因此"关闭"会一次离开它们。从正在运行的关卡中（通过调试控制台）打开的页面会返回关卡。从游戏内选项打开的图鉴会返回选项；从奖励页打开的图鉴关闭后继续进入下一关。

#### 过渡与淡入

- `MenuScreen.prepare()` 先加载下一页，再由 `ScreenTransition` 提交。只有资源准备、页面提交和成就页滑动会锁定输入；加载失败时保留调用页面和导航历史。
- 在主菜单与成就页之间切换时，两个页面在 0.75 秒内以原版的双 S 曲线垂直滑动 600 px，并重叠一个像素以避免出现接缝；主菜单在屏幕外继续保留。
- `PageFade` 属于所在的页面。普通奖励页从白色淡入；帮助页和便条类奖励从黑色淡入，并停止音乐、播放纸张音效。淡入持续 180 个 10 ms 的游戏逻辑步（正常速度下 1.8 秒），在页面激活时开始，随页面一同消失。它只负责绘制，淡入期间指针输入和键盘导航（如帮助页的回车、空格和 Esc）照常可用。
- 其他页面和对话框立即切换，没有额外的通用淡入。
