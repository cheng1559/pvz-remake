# 调试指令

调试控制台用于测试关卡、调整游戏状态，以及切换显示与输入选项。各平台的 Debug 与 Release 版本均可使用。

## 打开与关闭

| 操作 | 方法 |
| --- | --- |
| 用键盘打开 | 在没有文本框获得焦点时按 `/` |
| 用触屏打开 | 在移动设备上，或开启移动模式（`/mobile`）后，在 350 毫秒内双击窗口右下角（100 × 100 CSS 像素的区域） |
| 执行指令 | 按 Enter，或点击"确定"按钮 |
| 不执行直接关闭 | 按 Escape、点击"取消"按钮，或删除整行内容（包括开头的斜杠） |

游戏启动过程中，以及显示模组错误对话框时，无法打开控制台。

打开控制台会暂停关卡和游戏时钟（游戏时钟同时驱动玩法与表现）。关闭后恢复打开前的暂停状态，并保留期间通过 `/gamespeed` 设定的新速度。在速度为 0 时，输入、执行指令和关闭控制台均可正常进行。

## 输入指令

- 输入行以 `/` 开头，斜杠可以省略。
- 只接受可打印的 ASCII 字符，最多 120 个。
- 指令名和固定取值不区分大小写。植物、种子、僵尸、物品和成就的名称还会忽略空格、下划线和连字符，并可省略基础游戏的 `pvz:` 前缀：`snowpea`、`Snow_Pea` 和 `pvz:snowpea` 是同一个名称。其他模组的内容需要带上命名空间，如 `corn:cob_cannon`。
- 参数之间用空格分隔，单个参数可以用 `"…"` 或 `'…'` 括起来。
- 下文的语法中，`{值}` 为必填，`[值]` 为可选，`a|b` 列出可接受的取值。可选参数按位置识别：要填写 `[team]`，必须先填写它前面的所有参数。
- 行、列和卡槽编号都从 1 开始。显式指定的行可以是草坪上的任意一行，不受关卡启用了哪些行的限制。

### 补全与历史

- 按 Tab 补全行尾的单词，再按一次在候选项之间轮换。
- 指令名和固定取值（页面、`add|set`、阵营等）在任何地方都能补全。已安装的植物、种子、僵尸、物品和关卡名称只能在关卡中补全，因为这些名称由正在运行的关卡提供。
- 输入内容之后以淡色显示第一个补全结果，其后是其余参数的占位提示。在移动模式下，点击淡色部分即可填入并继续输入。
- 按上、下方向键可调出最近 64 条指令。历史记录保存在本机，重启后仍在；再次执行某条指令会把它移到最新的位置。

### 执行结果

| 结果 | 表现 |
| --- | --- |
| 成功 | 控制台关闭。开关类指令会在屏幕上提示新的状态，如"Recharge: off"；其他成功信息只写入日志，前缀为 `[Debug CLI]`。 |
| 语法错误：未知指令、参数数量不对，或取值不被接受、超出范围 | 输入行闪红并发出错误音效，保持打开以便修改。 |
| 条件不满足：没有正在进行的关卡、内容未安装、没有剩余波次等 | 控制台关闭并发出错误音效，在屏幕上提示原因。 |

下文引用的提示文字为基础游戏的英文原文，启用汉化资源包后显示为对应的中文。

### 指令的适用范围

- 页面、关卡、应用、速度、音量、显示和输入相关的指令在任何地方都可使用，只有 `/restart` 需要正在运行的关卡。
- 大多数草坪指令需要关卡处于游戏进行中：已过开场和选卡界面，且尚未分出胜负。否则会提示"/… requires an active level"。
- `/plant` 在关卡的任何状态下都可使用：开场期间、选卡界面中，以及分出胜负之后。
- `/money` 和 `/achievement` 在开场期间也可使用。关卡外的 `/money` 和任何地方的 `/achievement` 都需要玩家档案。
- 规则开关（`/cooldown`、`/suncost`、`/plantinvincible`、`/cheatseed`）和 `/collect` 在关卡的任何状态下都可使用；在关卡外只设定之后关卡的偏好。
- 关卡暂停时和速度为 0 时，指令照常生效。

## 指令

### 界面、关卡与应用

| 指令 | 作用 |
| --- | --- |
| `/goto {page}` | 打开菜单页面：`main`（主菜单）、`minigames`（迷你游戏）、`puzzle`（益智模式）、`survival`（生存模式）、`almanac`（图鉴索引）、`plants` 与 `zombies`（图鉴的植物页与僵尸页）、`store`（商店）、`garden`（休闲花园）、`mushroom`（蘑菇园）、`aquarium`（水族馆）、`tree`（智慧树）、`achievements`（成就）、`help`（帮助） |
| `/level {level}` | 重新开始指定关卡，跳过"是否继续存档"的提示。冒险模式关卡直接写编号：`1-1`、`adventure-1-1` 和 `pvz:adventure-1-1` 等价。其他关卡写完整 ID（含命名空间），如 `pvz:stress-test`。在关卡中执行时，未安装的关卡会被拒绝。 |
| `/restart` | 重新开始当前关卡，跳过"是否继续存档"的提示；需要正在运行的关卡 |
| `/reload` | 保存正在进行的关卡，然后从启动画面重新载入游戏 |
| `/quit` | 保存正在进行的关卡，然后退出游戏 |

用 `/level` 或 `/restart` 开始普通关卡时，会替换当前的关卡存档。临时关卡则保留原存档：先保存正在进行的关卡，临时关卡本身从不存档，结束后（无论胜负）回到主菜单，不发放奖励，也不推进冒险模式进度。

#### 测试关卡

| 关卡 | 内容 |
| --- | --- |
| `pvz:teams-demo` | 临时关卡，不发放成就。白天草坪，1000 阳光，固定的 8 张卡片。左侧每行预置植物方的向日葵和一株射手。右侧第 7–9 列预置 9 株面朝左的僵尸方植物（豌豆射手、双重射手、寒冰射手、坚果、大嘴花、土豆地雷、爆炸坚果）。双方互相攻击，同时有 4 波僵尸（普通僵尸、路障僵尸、铁桶僵尸，最后一波为旗帜波）从右侧穿过僵尸方植物进攻。可用 `/zombie normal 3 1 plants` 在这里放下植物方的僵尸。详见[阵营与迷糊菇](TEAMS.zh-CN.md)。 |
| `pvz:stress-test` | 临时关卡，不发放成就。白天草坪，9990 阳光，预置 40 株植物（每行 8 株），正式开始时立即生成 1023 只僵尸。`/perf plants` 和 `/perf zombies` 可关闭或重新开启植物、僵尸的绘制，以单独排查渲染开销。 |
| `pvz:sandbox-day`、`pvz:sandbox-night` | 临时沙盒关卡，不发放成就，分别在白天和黑夜草坪：9990 阳光，10 个空卡槽供 `/seed` 填入，除了放下的僵尸外没有僵尸（不来波次，关卡也不会结束）。不播开场，直接进入游戏：镜头不移动，卡槽和小推车一开始就在位，也不播“准备、安放、植物”。 |

测试关卡不属于冒险模式（没有 `adventureIndex`）：右下角显示关卡名，而不是关卡编号；首次冒险中，按关卡编号判断的规则对它们都按通关后重玩处理（例如会掉落金币）。

### 速度、波次与胜负

| 指令 | 作用 |
| --- | --- |
| `/gamespeed {0-10}` | 设定游戏时钟的速度，玩法与表现同时受其影响。可输入 0 到 10 之间的任意数（含小数）；`0` 为定格。该速度保持到游戏重启。 |
| `/step {1-1000}` | 让关卡立即运行指定数量的逻辑步，在一帧内算完：画面直接显示运行之后的状态，游戏随后按原速度继续。一帧最多运行 1000 步。暂停中的关卡同样会运行，之后保持暂停。 |
| `/win` | 立即赢得本关 |
| `/lose` | 立即输掉本关 |
| `/nextwave` | 立即生成下一波僵尸 |
| `/nextflag` | 跳到下一个旗帜波 |
| `/repick` | 在关卡中重新选卡 |

#### 波次

- `/nextwave` 立即生成下一波。若到达的是尚未预警的旗帜波，还会显示一大波预警并播放音效。
- `/nextflag` 跳过之前的波次，直接跳到下一个旗帜波。若一大波倒计时尚未开始，就开始该波的倒计时并显示预警，750 个逻辑步（正常速度下 7.5 秒）后出怪；若倒计时已在进行，则立即结束倒计时并出怪。这对应原版 `Board::KeyChar` 中的 `/` 作弊键。
- 没有剩余的对应波次时，两者都提示条件不满足（"No remaining zombie waves"、"No remaining flag waves"）。

#### 重新选卡

`/repick` 在战斗中重新选择种子栏：

- 关卡与音乐静止。铁铲离开，种子栏移到选卡位置，选卡界面从上方落下，镜头保持不动。界面中没有图鉴和商店按钮，种子栏显示在草坪上的僵尸、金币和阳光之上。
- 与开场的选卡界面相同，空格键不会暂停，Escape 和菜单按钮仍会打开菜单。
- 点击"开始战斗！"后，选卡界面移出、种子栏移回原位，完成后关卡与音乐继续。种子栏中的卡片保持选中，向前合拢填补空槽，种子栏的大小不变。
- 冷却规则与生存模式的重新选卡相同：种子栏原有的卡片保留原有冷却，无论是留在栏中还是重新选入；其他卡片立即可用。点击"开始战斗！"前不会弹出任何选卡警告，既没有缺少产阳光植物的提示，也没有关卡自身的教程警告。
- 种子栏由关卡发放的关卡也可以使用，结束后仍恢复为发放的种子栏；传送带关卡和没有种子栏的关卡不可使用（"This level has no seed bank to choose again"），正在选卡时也不可使用（"Finish choosing seeds first"）。
- 重新选卡不会存档：重新选卡期间保存的存档记录的是之前的种子栏（点击"开始战斗！"之后则是新选的种子栏），读档后直接进入战斗。
- 开启快捷键（`/hotkeys`）后，战斗中按 `R` 即执行该指令，在重新选卡界面中再按一次相当于点击"开始战斗！"。

### 植物、僵尸与草坪

| 指令 | 作用 |
| --- | --- |
| `/plant {plant_name} {row} {col} [team]` | 在指定格子创建植物。`team` 为 `plants`（默认）或 `zombies`。 |
| `/removeplant {row} {col}` | 移除指定格子中的植物；格子为空时也视为成功 |
| `/zombie {zombie_name} [row] [col] [team]` | 创建僵尸。`team` 为 `zombies`（默认）或 `plants`。 |
| `/damage {damage}` | 对草坪上所有僵尸（不分阵营）造成指定伤害，伤害须为正整数 |
| `/kill` | 立即移除草坪上所有僵尸，不分阵营 |
| `/griditem {grave\|crater} {row} {col} [team]` | 在指定格子放置墓碑或弹坑 |
| `/gravezombies` | 让每座墓碑立即召唤一只僵尸 |
| `/lawnmower {trigger\|reset} [row]` | 启动或重置指定行（或所有启用行）的小推车 |

#### `/plant`

- 直接创建已安装的植物，包括模组植物，如 `/plant corn:cob_cannon 3 1`。名称为植物种子的 ID，隐藏种子也可以（`explodenut`、`bowling-wallnut`、`bowling-explodenut`）。
- 不受格子占用、升级前置条件、种子栏是否有该种子、阳光消耗、冷却、教程以及关卡阶段与胜负的限制。手中持有的种子保持不变，植物注册的行为照常初始化。
- 只要求 ID 已安装、位置在草坪范围内；重叠的植物也会正常存档。
- `team` 为 `zombies` 时，创建一株面朝左、为僵尸作战的植物。详见[阵营与迷糊菇](TEAMS.zh-CN.md)。
- 用这种方式创建的植物不算玩家种植，因此依据玩家种植情况判定的成就会忽略它。详见[成就](ACHIEVEMENTS.zh-CN.md)。
- 用鼠标或触屏种植时仍遵循通常的规则。

#### `/zombie`

- 省略行时，僵尸出现在关卡启用行中随机的一行。
- 指定行但省略列时，僵尸从该行右侧边缘进场，与波次中的僵尸相同；指定列时，僵尸直接放在该格，与僵尸卡放下的僵尸相同。
- `team` 为 `plants` 时，创建植物方的僵尸：它向右行进，与僵尸方互相啃咬。它不是被迷糊菇控制的僵尸，因此不显示为紫色。详见[阵营与迷糊菇](TEAMS.zh-CN.md)。

#### 墓碑与弹坑

- `/griditem` 会替换格内已有的墓碑或弹坑，并清除占据该格的植物。
- 新放置的墓碑从升起开始。新放置的弹坑带有其种子的完整持续时间，需要已安装弹坑卡。
- 墓碑默认属于僵尸方，弹坑默认属于植物方；植物方的墓碑召唤植物方的僵尸。两者都会随关卡存档保存。
- `/gravezombies` 让每座墓碑立即召唤一只僵尸，包括刚放置的墓碑，以及关卡奖励已掉落的草坪上的墓碑。每座墓碑从关卡的加权僵尸池中抽取，召唤出的僵尸属于墓碑所在的阵营。草坪上没有墓碑或僵尸池为空时，不召唤任何僵尸。
- 僵尸升起需要 150 个逻辑步；游戏暂停时，在恢复后继续。
- 与该指令无关，关卡的最后一波开始 200 个逻辑步后，若关卡奖励尚未掉落，已完全升起的墓碑会各召唤一只僵尸。

#### 小推车

- `trigger` 启动该行（或所有启用行）待命的小推车。
- `reset` 在该行（或所有启用行）中小推车已离开的位置放下一辆新的小推车，无论原来那辆是否仍在行进。
- 没有任何小推车发生变化时，提示"No lawn mowers could be changed"。

### 种子、阳光、金币、掉落物与成就

| 指令 | 作用 |
| --- | --- |
| `/seed {slot} {seed_name} [team]` | 把种子放入卡槽，立即可用 |
| `/sun {add\|set} {number}` | 增加或设定阳光，结果限制在 0–9990 |
| `/money {add\|set} {number}` | 增加或设定金币，结果限制在 0–99999，同时写入玩家档案 |
| `/item {item_name} [row col]` | 以僵尸掉落物的形式掉落已安装的物品 |
| `/item award` | 再掉落一份本关奖励 |
| `/achievement give {achievement}` | 授予成就 |
| `/achievement reset [achievement]` | 重置一个成就或全部成就 |

#### `/seed`

- 用已安装的种子替换卡槽中的种子包，卡槽为空时则填入；卡槽从左侧起编号为 1。卡槽编号超出种子栏时，会提示可用的范围（如"Use slot 1-6"）。
- 新种子包立即可用，阳光消耗和冷却按该种子自身的数值计算。
- 种子可以是僵尸卡，如 `/seed 1 normal`，用它放下的是敌对僵尸。
- `team` 与种子自身的阵营不同时，种子包放下的是另一阵营的单位，种子包、手中和放置预览中的图像都会镜像显示：
  - 植物种子配合 `zombies` 种下僵尸方植物，它照常消耗阳光、进入冷却并遵循种植规则，但无法用铁铲铲除；
  - 僵尸卡配合 `plants` 放下植物方的僵尸，它不是被迷糊菇控制的僵尸，因此不显示为紫色；
  - 墓碑卡配合 `plants` 放下植物方的墓碑；
  - 弹坑卡（`/seed 1 crater`）本身属于植物方：可在除已有弹坑或墓碑以外的任意格子制造弹坑，格内的植物随之死亡；配合 `zombies` 时制造的弹坑会反向显示；
  - 省略 `team`，或填写种子自身的阵营，即恢复默认。

  详见[阵营与迷糊菇](TEAMS.zh-CN.md)。
- 替换手中持有的种子包时，光标上的种子会被清除。同一种子可以放入多个卡槽，各自独立冷却。
- 在传送带关卡中，卡槽指传送带上从左数起的卡片。指定种子会原地替换该卡片；`team` 同样适用。
- 该指令在游戏进行阶段开始后可用；重新选卡期间，要等选卡界面关闭后才可用。暂停时和速度为 0 时修改照常生效，并随关卡存档保存。

#### `/sun` 与 `/money`

- 数值为整数；配合 `add` 时，负数表示减少。结果限制在 0 到上限之间。
- `/sun` 需要关卡处于游戏进行中。
- `/money` 以原版的金币单位计数：1 枚金币为 $10，因此 `/money set 100` 显示为 $1,000。数值同时写入玩家档案。在关卡外直接修改玩家档案；在关卡中开场期间也可使用。修改后会像收集金币时一样显示钱袋；开场期间要等疯子戴夫出现后才显示。

#### `/item`

- 以僵尸掉落物的形式掉落已安装的物品：`sun`、`smallsun`、`coin_silver`、`coin_gold`、`diamond`，或带命名空间的模组物品。
- 同时指定行和列（要么都填，要么都不填）时掉落在该格；否则掉落在草坪中部附近。
- 使用 `award` 时，每执行一次就按当前波次和教程进度再掉落一份本关奖励。拾取其中任意一份即赢得本关。

#### `/achievement`

- `/achievement give {achievement}` 按 ID 授予成就，可省略 `pvz:`，如 `/achievement give sunny-days`。在关卡中由关卡授予，因此会像正常获得时一样显示提示并播放音效；在关卡外只写入玩家档案，等到下一次奖励页面再展示。
- 成就已获得，或在不发放成就的关卡（如各测试关卡）中执行时，提示条件不满足。
- `/achievement reset [achievement]` 在玩家档案和正在进行的关卡中重置指定成就，省略 ID 时重置全部成就，之后可以再次获得。
- 两者都需要玩家档案。详见[成就](ACHIEVEMENTS.zh-CN.md)。

### 规则开关

| 指令 | 作用 |
| --- | --- |
| `/cooldown` | 开关种子冷却；关闭时所有种子包立即可用 |
| `/suncost` | 开关阳光消耗 |
| `/plantinvincible` | 开关植物无敌 |
| `/cheatseed` | 开关全卡模式：选卡界面提供更多种子，卡槽全开并给出铁铲，并开放完整图鉴 |
| `/collect {auto\|click\|move}` | 设定阳光和金币的收集方式 |

在关卡中，这些指令修改本关规则，同时把新的状态记为偏好；之后每个新关卡都以这些偏好开始。在关卡外只设定偏好。偏好保存在本机。

#### `/collect`

- `click`（默认）：与原版相同，点击掉落物才收集。
- `auto`：每个普通掉落物（阳光、金币、钻石）一旦可以收集就自动收集。
- `move`：鼠标指针经过普通掉落物时收集。
- `auto` 和 `move` 都不会收集关卡奖励，关卡奖励仍需点击。

#### `/plantinvincible`

- 开启后，植物不会因僵尸啃咬或敌对植物的攻击（子弹、爆炸、喷雾、保龄球坚果、敌对冰川菇的冰冻伤害）而损失生命值。敌对寒冰射手的减速仍会让植物变慢，敌对冰川菇仍会冻住植物；小推车也不再碾压敌对植物。
- 迷糊菇仍会让啃咬它的僵尸或敌对植物倒戈，然后消失；敌对大嘴花仍可整株吞下植物。
- 对现有植物和之后种下的植物都生效。
- 植物自身的自毁、铁铲铲除和 `/removeplant` 照常生效。
- 默认关闭，保存在本机，跨关卡和重启保留。

#### `/cheatseed`

选卡界面：

- 选卡界面增加更多页面：
  1. 第 1 页是原版的卡片网格，其中包含全部种子，无论是否已拥有。
  2. 之后是各模组的种子，每个模组从新的一页开始，按模组的加载顺序排列。
  3. 然后是隐藏卡片（爆炸坚果、保龄球用的坚果、全部僵尸卡、墓碑卡和弹坑卡），单独成页，每张卡片位于其 `position` 指定的位置，属于植物方（弹坑卡本身就属于植物方）。
  4. 之后在僵尸方重复上述页面。一组卡片超过一页时延续到后续页面。
- 不属于种子自身阵营的卡片镜像显示；同一种子的两个阵营可以同时选择。
- 两个黄色的 `(Prev Page)` 与 `(Next Page)` 按钮用于翻页。它们按原版作弊键按钮 `(Debug Play)` 的样式绘制（FONT_BRIANNETOD12，颜色 255,240,0，高亮 200,200,255），位置是 DLC 在"开始战斗！"旁放置箭头的地方。在选卡界面上滚动鼠标滚轮也可翻页，每格一页，到两端后循环。模组可以重新设计这两个按钮（`LevelSeedChooser.pageTurners`）。
- 无需选满卡槽，不选卡片也可以开始战斗。
- 在选卡或重新选卡时关闭该开关，即使拥有的卡片比卡槽少，卡槽数也不变：选入全部可选的卡片后同样可以点击"开始战斗！"。
- 这些卡片参与判断是否打开选卡界面，因此首次冒险的早期关卡也会打开选卡界面。

关卡中：

- 开着该开关开始的关卡有全部卡槽（`seedBank.maxSlots`，10 个）：卡片槽升级视为已买满，仅限这一关，因此疯子戴夫不会推销卡槽。关卡中途再切换开关，本关的卡槽数不变。
- 铁铲以及关卡奖励的其他工具都视为已领取；自带工具设置的关卡仍只有它自己的工具（打僵尸没有工具）。

图鉴：

- 开放完整图鉴：显示并介绍全部植物和僵尸。
- 植物图鉴超过一页时，"关闭"左侧出现"上一页"和"下一页"按钮（"下一页"的图像为镜像）。点击这两个按钮或在卡片上滚动鼠标滚轮，可以翻到同样的模组种子页和隐藏卡片页；每张卡片显示阳光消耗和冷却（没有冷却的种子不显示冷却），并在植物所在的位置显示对应的僵尸或墓碑。
- 隐藏卡片共用一段占位说明（`ALMANAC_HIDDEN_DESCRIPTION`），显示在说明框中部。模组植物的文本表包含 `{nameKey}_DESCRIPTION_HEADER` 和 `{nameKey}_DESCRIPTION` 时会显示说明。
- 图鉴的各个入口保持不变。

该开关默认关闭，保存在本机。在关卡的任何状态下都可切换，包括开场期间、选卡界面中和分出胜负之后；已打开的选卡界面立即生效。在关卡外只设定偏好。

#### 分辨率与锐度

- 默认情况下，游戏按原版的方式绘制：以 800×600 布局的一个单位对应一个像素（宽度随窗口比例扩展），再把这幅画面放大到整个窗口。场景仍只绘制一次：摄像机绘制到这幅小画面中，并且仍由它接收指针输入（引擎的 `Camera.presentedOnWindow`）。
- `/highresolution` 改为按窗口的实际像素直接绘制到窗口，同样的美术资源会比原版显示得更清晰。默认关闭，保存在本机。
- `/sharpness {0-1}` 设定放大后像素的锐度，并保存在本机。两个像素之间的边缘在 `1 - sharpness` 个屏幕像素的宽度内过渡：`0` 在整个屏幕像素内过渡（边缘最柔和），`1` 接近最近邻缩放（边缘清晰；缩放比例不是整数时，像素大小可能相差一个像素）。默认值为 0.5。
- 锐度作用于放大到窗口的那幅画面的像素。开启 `/highresolution` 后没有这幅画面，锐度改为作用于基础位图字体：其字形按面积采样，缩小后笔画依然均匀，整数缩放比例不受影响。

#### 种子包插图

- 种子包中的植物或僵尸由其视图绘制，姿势与原版缓存插图相同，每个屏幕像素取四个采样，这正是原版缓存插图缩放到种子包后的效果。
- `/tilted` 放大并倾斜插图：植物放大到 1.5 倍并顺时针旋转 12°，僵尸放大到 2 倍。植物只在插图区域内侧的左边框和下边框处裁剪，顶部和右侧可以超出。
- 种子包背景、价格和点击区域保持原尺寸，切换开关时复用已加载的插图。手中持有的种子和草坪上的放置预览从不倾斜。
- 尚无视图绘制其植物的种子，显示原版的缓存插图。
- 默认关闭，保存在本机。

#### 鼠标指针

- `/cursor` 在原版鼠标指针与系统指针之间切换。原版指针包括大箭头、悬停在可点击对象上时的手指，以及拖动对话框时的张开手掌；文本框仍使用系统的 I 形光标。
- `npm run build:content` 从原版程序中提取这些指针图像，放入基础内容包；资源包可以按 ID 替换。
- 默认开启，保存在本机。

#### 帧率、碰撞箱、血条与槽位号

- `/fps` 在原版 800×600 游戏区域的左下角显示或隐藏白色的帧率计数，宽屏拓展不会移动它的位置。计数按真实时间统计实际绘制的帧数，不受游戏暂停或速度影响。默认关闭，保存在本机。
- `/hitboxes` 在草坪上用 1 像素宽的线框标出植物的身体（绿色）与攻击范围（红色：大嘴花、土豆雷、保龄球坚果的攻击范围，小喷菇、大喷菇的射程），既未死亡也不在倒下过程中的僵尸的身体（绿色）与啃咬范围（红色），以及子弹和小推车的碰撞范围（红色；待命小推车的范围就是僵尸触发它的区域）。默认关闭，保存在本机。
- `/hp` 在植物和僵尸的碰撞箱上方显示血条：植物为绿色；僵尸依次为身体（红色）、头盔（黄色）和盾牌（蓝色），以三者的满血之和为满格。默认关闭，保存在本机。
- `/id` 在植物和僵尸的碰撞箱左下角显示它们在列表中的槽位号（见[实体数据](MODS.zh-CN.md#实体数据)）。默认关闭，保存在本机。

#### 焦点、振动、操作方式、全屏与音量

- `/autopause`：窗口失去焦点或被隐藏时，可以暂停的关卡会打开暂停菜单（打开着菜单页面、对话框或控制台时除外），同时静音。关闭后，切换到其他窗口时既不暂停也不静音；游戏被隐藏（切换到其他标签页、最小化窗口、应用转入后台）时仍会静音。默认开启，保存在本机。
- `/haptics` 立即开关全部触屏振动。默认开启，保存在本机。
- `/mobile` 切换移动模式。移动模式下，草坪忽略鼠标，改为响应触屏：按住种子包或铁铲，拖到草坪上松开即可使用；手指划过阳光和金币即可收集。详见 UI 中的[触屏](UI.zh-CN.md#触屏)一节。在移动设备上默认开启，其他设备默认关闭，只在本次运行期间有效。
- `/fullscreen` 切换全屏，与"选项"中的全屏设置一样保存在游戏设置中。原生移动版始终全屏（"Windowed mode is unavailable on mobile"）；不支持全屏的浏览器会提示"Full screen is unavailable"。
- `/resize` 决定 Windows 与 macOS 的窗口能否调整大小，默认关，保存在本机。关闭时窗口高度固定为 600，宽度为 600 × 当前宽高比，并限制在游戏允许的宽高比范围内：没装宽屏模组时就是 800×600；装了宽屏模组时宽度在 800～1400 之间，只能横向拖动；窗口也不能最大化。关闭时窗口按当前宽高比缩放到这个高度；处于全屏时，退出全屏后再缩放。打开后可以在宽高比范围内自由调整。这里的 600 是游戏的像素，高 DPI 屏幕会像默认窗口一样把它放大。网页版和移动设备会提示"Window resizing is unavailable"。
- `/music` 和 `/sfx` 以 0 到 100 的整数设定音量，通过设置接口保存，与"选项"中的设置相同。

#### 性能开关

`/perf {category}` 关闭某一类内容，或重新开启，以单独排查其开销。各类默认都开启，开关状态只在本次运行期间有效。

| 类别 | 关闭的内容 |
| --- | --- |
| `plants` | 植物的绘制 |
| `zombies` | 僵尸的绘制 |
| `particles` | 粒子效果 |
| `sfx` | 音效 |
| `logic` | 游戏逻辑：关卡停止推进，但画面照常绘制 |

#### 模组管理器

`/mod` 打开通用的模组管理器，这是唯一的管理入口，不接受参数。

- 点击"导入"选择本地 ZIP 文件，可一次选择多个。进度对话框的标题为 `Importing...`。
- 在窗口中启用、停用、卸载条目，或调整条目顺序（即优先级），然后点击"应用"。
- 修改启用状态或正在使用的资源时会提示重启。确认后先保存正在进行的关卡，再重启游戏；重启前仍使用当前运行的代码和资源。点击"取消"会丢弃未应用的修改。
- 已安装的模组保存在本地，与原始 ZIP 文件无关，可以用相同 ID 的包更新。
- 优先级更高（加载更晚）的模组覆盖相同 ID 的资源。没有提供的 ID 使用原版资源；已声明但加载失败的资源不会回退。
- ZIP 是唯一的安装格式。游戏不内置 HD 资源，HD 资源以资源包形式单独提供。HD 资源包不包含 Pico129 和 Pix118Bold 两套字体。
- 已安装模组列表准备好之前，管理器显示文本 `LOADING`（`LOADING...`）。

包格式与安装方法见[模组](MODS.zh-CN.md)。

## 快捷键

开启快捷键（`/hotkeys`，默认关闭，保存在本机）后，每个种子包上显示对应的数字键，铁铲上显示对应的字母键。

| 按键 | 作用 |
| --- | --- |
| `1`–`9`、`0` | 选取第 1–10 个卡槽中的种子包，或传送带上从左数起对应位置的卡片。手中持有其他种子包或铁铲时，直接换成该种子包；再按手中种子包对应的键则放回。 |
| `F` | 拿起铁铲，或把铁铲放回。手中持有植物时，像数字键切换种子包一样直接换成铁铲。 |
| `R` | 执行 `/repick`；在重新选卡界面中再按一次相当于点击"开始战斗！" |
| `S` | 切换 `/suncost`，效果与输入该指令相同 |
| `C` | 切换 `/cooldown`，效果与输入该指令相同 |

快捷键只在关卡中、且没有对话框遮挡草坪时生效。`F` 在可以拿起铁铲时即可使用；其他按键要等关卡开场结束后才可使用，数字键只在游戏进行中可用。

## 指令的执行过程

1. `GameApp` 打开对话框（`client/dialogs/DebugCliDialog.ts`），对话框基于 `UI.dialog` 和 `UI.input` 构建。有关卡正在运行时，先向服务端请求 `catalog`，即已安装的植物种子、种子、僵尸、物品和关卡列表，用于补全和 `/level` 的检查。
2. `executeDebugCliCommand`（`platform/debug/DebugCliCommands.ts`）用 `shared/debug/DebugCli.ts` 中的 `parseDebugCliCommand` 解析输入，该文件的 `specs.list()` 定义了所有指令的语法。客户端自己的指令直接在这里执行：页面、关卡与应用、速度、显示与输入开关、`/mod`，以及通过菜单接口的玩家档案执行的关卡外 `/money` 和 `/achievement`。音频与全屏设置通过菜单接口的设置保存。
3. 玩法指令以原始文本转发：`LevelController.debugCommand` → `LocalIntegratedGame.debugCommand` → `IntegratedGameClient`，由后者发送 `debugCommand` 数据包。
4. `IntegratedGameHost` 只在允许调试指令时（本地一体化游戏会开启）把数据包加入队列，否则以 `unsupported-command` 拒绝。
5. 会话在逻辑步之间把它作为会话命令执行（`server/session/commands.ts`）：再次解析文本，调用 `executeDebugGameCommand`（`server/debug/debugCommands.ts`），由它校验指令并修改权威世界，从不直接修改客户端的快照。
6. 结果通过 `debugResult` 数据包返回。`LocalIntegratedGame` 等待该结果，关卡视图与世界同步后，控制台再显示结果。

结果类型：

- `debugSuccess` 和 `debugSyntax` 携带的信息只写入日志。
- `debugCondition` 携带文本表的键及其参数，由客户端格式化后显示在屏幕上。
- `debugSwitched` 额外附带提示 `DEBUG_SWITCH_ON` 或 `DEBUG_SWITCH_OFF`，以及开关名称的键 `DEBUG_SWITCH_{NAME}`（`/perf plants` 对应 `DEBUG_SWITCH_PERF_PLANTS`）。

规则与偏好：

- 规则开关作用于会话的 `DebugRulesResource`。冷却、阳光消耗、植物无敌、收集方式和全卡模式还作为调试偏好保存在 `GameDebugSettings` 中，由 `LevelController` 应用到每个新关卡；在关卡外，这些指令只设定偏好。
- `GameDebugSettings` 把保存在本机的设置存放在本地存储的 `pvz-remake:debug:settings` 键下，把指令历史存放在 `pvz-remake:debug:cli-history` 键下。
- 快捷键 `S` 和 `C` 与控制台一样，通过 `executeDebugCliCommand` 执行 `/suncost` 和 `/cooldown`；`R` 向关卡发送 `/repick`（`client/level/LevelInputPresenter.ts`）。

模组通过 `host.around` 包装 `specs.list` 和各个 `executor` 对象来添加指令，详见[模组文档](MODS.zh-CN.md#扩展调试指令)。
